Один столбик — один день COTD: чем ниже столбик, тем ближе дивизион к 1-му (ниже — сильнее). Шкала обрезана по 95-му перцентилю, чтобы редкие слабые дни не сжимали остальные: такие дни прижаты к верху, точный дивизион — в подсказке при наведении. У дней без дивизиона столбика нет.
