Дивизионы по дням · 2020

дивизион дняниже — ближе к 1-му дивизиону

Один столбик — один день COTD: чем ниже столбик, тем ближе дивизион к 1-му (ниже — сильнее). Шкала обрезана по 95-му перцентилю, чтобы редкие слабые дни не сжимали остальные: такие дни прижаты к верху, точный дивизион — в подсказке при наведении. У дней без дивизиона столбика нет.

место в миретренд

Точки — дни с результатом, сплошная линия соединяет их, пунктир — тренд по этим дням. Ось Y логарифмическая: ниже — лучше. Шкала обрезана по 95-му перцентилю, чтобы редкие провальные дни не сжимали остальные: такие точки прижаты к верхней границе, точное место — в подсказке при наведении.
